Webservices: WSAA + WSFEv1

Orden práctico para autenticarte y pedir un CAE. El transporte es SOAP/XML sobre HTTPS. Detalle normativo: PDFs oficiales (copia local en este índice).

RG 4291 · V.4.8 RG 5616 PDFs
Manual WSFEv1 Manual WSAA Ir a loginCms

En corto

  1. Certificado del CUIT + asociación al WSN wsfe + punto de venta electrónico.
  2. WSAA loginCms → token + sign (cachear ~12 h).
  3. WSFEv1 FECompUltimoAutorizado → número siguiente.
  4. WSFEv1 FECAESolicitar → CAE / Resultado (incluir CondicionIVAReceptorId, RG 5616).

Prerrequisitos

  • CUIT y clave fiscal
  • Certificado del ambiente (homo ≠ prod)
  • Asociación al WSN Facturación Electrónica (wsfe)
  • Punto de venta electrónico
  • Reloj sincronizado (NTP; zona GMT-3 en los manuales)

Adhesión / certs: ver PDFs WSASS y WSAA en Fuentes.

1. WSAA — loginCms

Fuentes: Manual Dev · Especificación 1.2.2.

SOAP loginCms WSAA

TRA (XML a firmar)

LoginTicketRequestservice=wsfe
<?xml version="1.0" encoding="UTF-8"?>
<loginTicketRequest version="1.0">
  <header>
    <uniqueId>1710000000</uniqueId>
    <generationTime>2026-09-23T21:55:00-03:00</generationTime>
    <expirationTime>2026-09-24T08:00:00-03:00</expirationTime>
  </header>
  <service>wsfe</service>
</loginTicketRequest>
  1. Firmar CMS SignedData (SHA1+RSA) con cert + clave.
  2. Codificar CMS en Base64.
  3. Invocar loginCms.
  4. Extraer token y sign; reutilizar mientras viva (~12 h).
