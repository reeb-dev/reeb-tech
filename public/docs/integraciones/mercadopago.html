Flujo típico (según la doc de MP)

  1. Credenciales de la cuenta del comercio Access Token solo en servidor. Nunca en el navegador ni en un repo público.
  2. Crear preferencia API de preferencias → init_point / sandbox_init_point.
  3. Webhook Recibir notificación y consultar el pago por API antes de marcar cobrado.
  4. Producción Solo con credenciales de producción y HTTPS.

Checklist

  • Prueba en sandbox con preferencia + pago de prueba
  • Webhook valida el pago por ID vía API
  • Token fuera de git y del front
  • URLs de retorno / notificación en HTTPS
