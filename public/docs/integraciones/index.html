Cómo funciona (4 pasos)

  1. Configurás el comercio CUIT + certificado + PV electrónico en el servidor (ARCA_*).
  2. Cerrás una venta En el panel o vía API de ventas; te queda un saleId.
  3. POST al endpoint de CAE Tu código (o Postman) llama /api/arca/invoices/{saleId}.
  4. Guardás el CAE Respuesta JSON con cae, caeVto, result.
