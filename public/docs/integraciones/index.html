Cómo funciona

  1. Certificado del CUIT Homologación o producción, asociado al WSN wsfe, con punto de venta electrónico.
  2. WSAA te da el ticket Firmás el TRA, llamás loginCms, cacheás token + sign.
  3. WSFE autoriza el comprobante Pedís el último número y después el CAE con FECAESolicitar.
  4. Contrastás con el PDF Ante duda, gana el manual vigente del organismo.
