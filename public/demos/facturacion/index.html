Facturación de ejemplo

El comprobante, el vencimiento y el aviso de cobro.

Un libro para no mezclar borrador, emitido y a cobrar. Los montos se suman solo de estas filas y están marcados como ejemplo. No es un sistema fiscal.

Borrador

Todavía no se emite. Falta el ítem, el motivo de la nota o la fecha.

Emitido

Ya tiene tipo y número. Falta enviarlo o acusar recibo.

A cobrar

Venció o está por vencer. El aviso de cobro queda escrito en la ficha.

Cómo se usa el libro

1. Se carga el comprobante

Tipo, número, receptor, monto de ejemplo y vencimiento.

2. Se emite

Pasa de borrador a emitido. El número no se inventa como métrica: es el del comprobante de ejemplo.

3. Se avisa el cobro

Si hay vencimiento, la ficha guarda el aviso. El total de arriba es la suma de esas filas.
